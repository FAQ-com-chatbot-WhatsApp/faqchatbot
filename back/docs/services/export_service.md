# Implementation Plan: Export Service (`export_service.py`)

## Brief description of the requirements and goals of the feature
This service is responsible for generating downloadable reports in different formats, specifically PDF and Excel. It takes structured report data (likely generated by an analytics service) and transforms it into professionally formatted, human-readable documents. This is a crucial feature for business users who need to analyze performance metrics, track conversions, and gain insights from the application's data offline.

## Architecture and design
The `ExportService` is a static utility class, meaning its methods can be called directly without needing to create an instance of the class. It uses two main libraries for file generation:

- **`reportlab` for PDF Generation**:
    - `export_performance_report_pdf`: This method constructs a PDF document from scratch.
    - It defines styles for titles, headings, and tables to ensure a consistent and professional look.
    - It builds the document section by section (e.g., "Bot Response Time," "Handoff Rate"), creating tables and paragraphs for each data point.
    - It uses `SimpleDocTemplate` to manage the layout, page breaks, and rendering of elements.
    - The final PDF is generated in an in-memory buffer (`io.BytesIO`) and returned as a byte string, which can then be sent as a file download in an HTTP response.

- **`openpyxl` for Excel Generation**:
    - `export_performance_report_excel`: This method creates a multi-sheet Excel workbook.
    - It defines cell styles for headers and data to make the spreadsheet easy to read.
    - It creates separate worksheets for different aspects of the report ("Resumo," "Horários de Pico," "Distribuição por Status"), which is a best practice for organizing complex data in Excel.
    - It populates the cells with the report data and adjusts column widths for better readability.
    - Similar to the PDF method, the final Excel file is saved to an in-memory buffer and returned as a byte string.

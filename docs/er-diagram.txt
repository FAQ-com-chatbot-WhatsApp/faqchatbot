ASCII ER Diagram (Simplificado)

 contacts (id PK) 1---N conversations (contact_id FK)
 conversations (id PK) 1---N messages (conversation_id FK)
 flows (id PK) 1---N conversations (flow_id FK opcional)
 conversations (id PK) 1---N conversation_events (conversation_id FK)
 webhooks (id PK) -> usados para entrada de mensagens externas

Legenda:
PK = Primary Key
FK = Foreign Key
1---N = Relação um para muitos

Estruturas Principais:
contacts: metadados de contato (telefone, email, identificadores externos)
flows: definição JSON do fluxo conversacional
conversations: instâncias de execução de fluxos para contatos
messages: mensagens trocadas (in/out) com conteúdo flexível JSON
conversation_events: eventos relevantes (status, transições, erros)
webhooks: tokens para canais externos (ex: WhatsApp) futuros
